## CodeAlpha Data Science Internship Project

This project uses Machine Learning to classify iris flowers into different species based on flower measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

## Features
- Data Visualization
- Model Training
- Accuracy Evaluation
- Flower Prediction
